PixelScope

개인정보처리방침

시행일: 2026년 8월 27일

PixelScope는 사용자의 데이터를 외부 서버로 전송하지 않습니다.
  • 측정, 색상 분석 및 캡처는 사용자의 브라우저 내부에서 처리됩니다.
  • 광고, 분석 또는 사용자 추적 서비스를 사용하지 않습니다.
  • 사용자 데이터를 판매하거나 제3자와 공유하지 않습니다.

1. 적용 범위

본 개인정보처리방침은 Chrome 확장 프로그램 PixelScope(이하 “확장 프로그램”)에 적용됩니다. 확장 프로그램의 목적은 현재 웹페이지의 레이아웃과 시각 요소를 측정하고, 색상을 확인하며, 사용자가 요청한 화면을 캡처하는 것입니다.

2. 처리하는 데이터

확장 프로그램은 기능 제공에 필요한 최소한의 데이터를 다음과 같이 처리합니다. 아래 데이터는 개발자 서버로 전송되지 않습니다.

웹사이트 콘텐츠

선택한 요소의 위치와 크기, 현재 웹페이지의 픽셀, 화면 전체 피커로 사용자가 직접 선택한 한 픽셀의 색상, 사용자가 요청한 객체 또는 전체 페이지 캡처 이미지와 캡처 파일명 생성을 위한 페이지 제목을 처리합니다.

사용자 활동

도구 작동에 필요한 포인터 위치, 클릭, 드래그, 스크롤과 도구 제어 키(Escape 및 방향키)를 일시적으로 처리합니다. 이러한 입력을 활동 기록으로 작성하거나 외부로 전송하지 않습니다.

사용자 설정

사용자가 선택한 측정 단위, 컬러 피커 범위와 색상 복사 형식을 Chrome 로컬 저장소에 보관합니다.

확장 프로그램은 이름, 이메일 주소, 위치, 건강·금융·결제·인증 정보 또는 방문 기록 목록을 별도로 수집하지 않습니다.

3. 데이터 이용 목적

  • DOM 요소 및 자유 영역의 크기 측정
  • 현재 웹페이지 또는 화면 전체에서 사용자가 직접 선택한 한 픽셀의 색상 분석과 클립보드 복사
  • 선택한 객체 또는 전체 페이지의 PNG 캡처 생성
  • 측정 단위, 컬러 피커 범위와 색상 복사 형식 설정 복원

처리된 데이터는 위 기능 제공 외의 광고, 프로파일링, 신용도 판단, 대출 또는 시장 조사 목적으로 사용되지 않습니다.

4. 저장 위치 및 보관 기간

캡처 이미지

완성된 PNG 이미지는 결과 뷰어에 전달하기 위해 확장 프로그램 전용 IndexedDB에 임시 저장됩니다. 뷰어 탭을 닫으면 삭제되며, 비정상 종료 등으로 남은 데이터는 생성 후 1시간이 지나면 다음 정리 시 삭제됩니다.

사용자 설정

측정 단위, 컬러 피커 범위와 색상 복사 형식은 chrome.storage.local에 저장되며, 사용자가 설정을 변경하거나 확장 프로그램 또는 해당 브라우저 데이터를 삭제할 때까지 보관됩니다.

화면 전체 피커는 사용자가 직접 클릭한 한 픽셀의 불투명 sRGB 색상만 메모리에서 처리하며 화면 이미지나 선택 기록을 저장하지 않습니다.

포인터 위치, 클릭, 드래그, 스크롤 및 키 입력은 기능 수행 중에만 메모리에서 처리하며 별도의 활동 기록으로 저장하지 않습니다. 모든 웹페이지에 주입되는 최소 단축키 리스너는 Alt + ` 조합 여부만 확인하고 다른 키 입력을 저장하거나 전송하지 않습니다.

5. 클립보드 및 파일 저장

색상 값과 캡처 이미지는 사용자가 복사 버튼 또는 색상 선택 동작을 직접 실행한 경우에만 클립보드에 기록됩니다. 확장 프로그램은 클립보드의 기존 내용을 읽지 않습니다.

PNG 파일은 사용자가 저장 버튼을 누른 경우에만 브라우저의 일반 파일 다운로드 방식으로 저장됩니다.

6. 외부 전송 및 제3자 제공

확장 프로그램은 사용자 데이터를 개발자 또는 제3자의 서버로 전송하지 않으며, 판매·대여·공유하지 않습니다. 외부 분석 도구, 광고 SDK, 추적 픽셀 및 원격 실행 코드를 사용하지 않습니다.

7. 권한 사용

  • <all_urls>: 웹페이지가 처음 열릴 때 Alt + ` 단축키 입력만 감지하는 최소 리스너를 자동 주입합니다.
  • activeTab: 사용자가 도구를 실행한 현재 탭에 일시적으로 접근합니다.
  • scripting: 확장 프로그램에 포함된 측정·색상·캡처 및 화면 전체 스포이드 실행 코드를 현재 탭에 주입합니다.
  • storage: 측정 단위, 컬러 피커 범위와 색상 복사 형식을 저장합니다.
  • clipboardWrite: 사용자가 요청한 색상 값 또는 PNG 이미지를 클립보드에 기록합니다.

8. 사용자 선택 및 삭제

사용자는 언제든지 도구를 종료하거나 확장 프로그램을 제거할 수 있습니다. 확장 프로그램을 제거하면 Chrome이 관리하는 로컬 설정과 확장 프로그램 전용 저장 데이터도 함께 제거됩니다. 저장한 PNG 파일과 사용자가 클립보드에 복사한 데이터는 각각 운영체제와 사용자의 관리 범위에 속합니다.

9. 방침 변경

기능 또는 데이터 처리 방식이 변경되면 본 방침을 갱신하고 시행일을 변경합니다. 중요한 변경이 있는 경우 Chrome Web Store 항목 정보 또는 확장 프로그램 화면을 통해 알립니다.

10. 문의

개인정보 처리와 관련된 문의는 Chrome Web Store의 PixelScope 항목에 표시된 개발자 문의 채널을 이용해 주세요.
